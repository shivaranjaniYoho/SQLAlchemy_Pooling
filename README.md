# SQLAlchemy ORM and Pooling

## Project Description
This task demonstrates how to use SQLAlchemy ORM with PostgreSQL. It covers database models, relationships, connection pooling, and session management.

## Requirements
- Python
- PostgreSQL
- SQLAlchemy
- psycopg2-binary
- VS Code

## Tasks Completed

### 1. ORM Models
- Created Customer and Order models.
- Used Base, Column, and ForeignKey.
- Created a one-to-many relationship between Customer and Order.

### 2. Insert Data
- Added 3 customers.
- Added 2 orders for each customer.
- Used session.add() and session.commit().

### 3. Query Orders
- Retrieved customer orders using the ORM relationship.
- Used customer.orders without writing a manual SQL JOIN.

### 4. Connection Pooling
- Set pool_size=5.
- Set max_overflow=2.
- Maximum configured pool connections: 7.

### 5. Session Management
- Created one session per request.
- Opened, used, and closed sessions.
- Used try and finally to ensure the session closes.

### 6. Bonus Challenge
- Enabled SQL logging using echo=True.
- Observed SQL queries generated by SQLAlchemy.
- Identified the SELECT query used when accessing customer.orders.

## How to Run

Install the required packages:

```bash
python -m pip install sqlalchemy psycopg2-binary
```

Create a PostgreSQL database named `sqlalchemy_practice`.

Update the PostgreSQL username and password in `main.py`.

Run the program:

```bash
python main.py
```
